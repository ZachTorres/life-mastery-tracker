🔒 DNS-Level Blocking (Free)

CleanBrowsing DNS

Blocks adult content at the network level. Harder to bypass than browser extensions.

Family Filter DNS Servers:

185.228.168.168
185.228.169.168
How to set up on Windows
  1. Open Control Panel > Network and Internet > Network and Sharing Center
  2. Click on your connection, then Properties
  3. Select "Internet Protocol Version 4 (TCP/IPv4)" > Properties
  4. Select "Use the following DNS server addresses"
  5. Enter: 185.228.168.168 and 185.228.169.168
  6. Click OK on all windows

📱 Phone-Specific Solutions

iPhone
  • Use Screen Time with a passcode someone else sets
  • Enable "Limit Adult Websites" in Content Restrictions
  • Have someone else set the Screen Time passcode
Android
  • Install BlockerX or Detoxify
  • Use Google Family Link (have someone else control it)
  • Enable SafeSearch in Google settings

💻 Browser Extensions (Least Secure)

Warning: These can be easily disabled. Use in addition to other methods, not alone.

  • BlockSite - Block specific websites
  • StayFocusd - Limit time on distracting sites
  • Cold Turkey - Strict blocker with scheduling

⚠ THE KEY TO SUCCESS

1. Give control to someone else. Have an accountability partner set passwords you don't know.

2. Use multiple layers. DNS blocking + Accountability software + Phone restrictions.

3. Remove easy access. Delete social media apps that trigger you.

4. Create friction. The harder it is to access, the more time you have to choose wisely.
